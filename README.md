## 🎯 주요 프로젝트

### Part 1: 임베디드 시스템
- **부트캠프** - CANoe 차량 경보 시스템 (V-Cycle 개발)
- **졸업작품** - 스마트 분리수거 (YOLOv8 + 임베디드 제어)
- **현장실습** - 산업 제어 시스템 (Single Master 패턴)
- **기말과제** - IoT 스마트 도어락 (Raspberry Pi)

### Part 2: 데이터 분석 & 웹앱
- **RUL 예측 시스템** - 사출성형 기계의 남은 수명 예측
  - EDA 클러스터링 분석 (DBSCAN, OPTICS, HDBSCAN)
  - 오토인코더 기반 이상 탐지
  - Streamlit 대시보드
