#### 1. [CANoe 차량 경보 시스템](https://github.com/leehyeonjun90/project-bootcamp)

- **기술**: CANoe, CAPL, C/C++, CAN 통신

#### 2. [스마트 분리수거 시스템](https://github.com/leehyeonjun90/project-graduation)
**졸업작품 - AI 영상인식 + 임베디드 제어**
- 🎥 YOLOv8 딥러닝으로 물품 자동 분류 (95% 정확도)
- 🔌 Raspberry Pi + Arduino 3계층 분산 제어
- ⚡ 전력 문제 물리적으로 해결 (공통 그라운드 재설계)
- 🏆 캡스톤 디자인 경진대회 우수상
- **기술**: YOLOv8, Arduino, C/C++, GPIO, PWM, UART

#### 3. [산업 제어 시스템 - 절전 기능](https://github.com/leehyeonjun90/project-internship)

- ☕ 산업용 커피 디스펜서 PLC/MCU 제어
- 🔧 절전 기능 개발로 제어 충돌 발생
- 💡 **Single Master 패턴**으로 안정성 확보
- 🎯 24시간 연속 가동 시스템 구현
- **기술**: PLC, MCU, 상태 머신, 시스템 설계

#### 4. [스마트 도어락](https://github.com/leehyeonjun90/project-capstone)

- **기술**: Raspberry Pi, GPIO, PWM, 보안 시스템
