# RUL 예측 시스템

**산업 4.0 예지 보전 플랫폼 - 사출성형 기계의 남은 수명 예측**

---

## 📌 프로젝트 개요

### 한 문장 요약
**오토인코더 + 로지스틱 회귀로 기계의 남은 수명(RUL)을 예측하는 완전한 예지 보전 시스템**

### 목표
**"이 기계는 앞으로 언제쯤 망가질 거야?"를 정확히 예측**

---

## 🎯 시스템 목표

```
Before (반응형 유지보수):
고장 → 생산 중단 → 비상 수리 (비용 많음)

After (예지 보전):
사전 예측 → 계획 수리 → 생산 무중단 (비용 절감)
```

---

## 📊 데이터 분석 파이프라인

```
1. 센서 데이터 수집
   ↓
2. 데이터 로드 & 정규화
   (MinMaxScaler 0~1 범위)
   ↓
3. 오토인코더 (비지도학습)
   - 정상 데이터만 학습
   - 재구성 오류로 이상 탐지
   ↓
4. 로지스틱 회귀 (지도학습)
   - PassOrFail 판단
   - 성능 지표 계산
   ↓
5. RUL 계산
   - 남은 수명 예측
   - 유지보수 시기 판정
   ↓
6. Streamlit 대시보드
   - 실시간 데이터 표시
   - 이상 탐지 결과
   - RUL 값 표시
```

## 🛠️ 기술 스택

### Frontend
- **Streamlit** - 웹 인터페이스 (다크 모드)
- **Altair, Matplotlib, Seaborn** - 시각화

### Backend
- **Python** - 데이터 처리
- **Pandas, NumPy** - 데이터 조작

### Machine Learning
- **TensorFlow/Keras** - 오토인코더
- **Scikit-learn** - 로지스틱 회귀 & 전처리
- **MinMaxScaler** - 정규화

---

## 🤖 2가지 머신러닝 모델

### 1️⃣ 오토인코더 (비지도학습)
```
✓ 정상 데이터로만 학습
✓ 이상 데이터는 높은 재구성 오류
✓ 이상 탐지에 최적화

특징:
- EarlyStopping (patience=10): 과적합 방지
- 재구성 오류로 이상 스코어 계산
```

### 2️⃣ 로지스틱 회귀 (지도학습)
```
✓ PassOrFail 판단 (정상/비정상)
✓ 정확도, 재현율, 정밀도 계산
✓ 분류 성능 평가

특징:
- 신뢰도 높은 분류
- 확률 기반 의사결정
```

## 📊 핵심 기능

| 기능 | 설명 | 기술 |
|------|------|------|
| **이상 탐지** | 정상 vs 비정상 판별 | 오토인코더 |
| **분류** | PassOrFail 판단 | 로지스틱 회귀 |
| **RUL 예측** | 남은 수명 계산 | 머신러닝 모델 |
| **정규화** | 0~1 범위로 스케일링 | MinMaxScaler |
| **성능 평가** | 정확도, 재현율, 정밀도 | Scikit-learn metrics |
| **시각화** | 대시보드 | Streamlit |

## 📈 대시보드 기능

### Main 페이지
- 실시간 RUL 값 표시
- 각 로트별 남은 수명(일 수)
- 유지보수 시기 자동 판정
- 다크 모드 UI

### EDA 페이지
- 클러스터링 분석 (DBSCAN, OPTICS, HDBSCAN)
- 데이터 분포 시각화
- 이상 패턴 식별

### Anomaly Detection 페이지
- 사용자가 로트 번호 선택
- 신뢰도 구간 시각화
- 이상점 명시적 표시
