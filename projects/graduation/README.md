# 스마트 분리수거 시스템

**졸업작품 - AI 영상인식 + 임베디드 제어**

---

## 📌 프로젝트 개요

### 한 문장 요약
**YOLOv8 딥러닝 + Arduino 임베디드 제어로 자동 물품 분류하는 지능형 분리수거 시스템**

---

## 🎯 핵심 기능

### 1. AI 물품 인식
- YOLOv8로 플라스틱, 종이, 금속 분류 (95% 정확도)
- Raspberry Pi에서 실시간 추론

### 2. 자동 분류 및 배출
- 3가지 모터 제어로 물품 배출
- 자동 센서 감지

### 3. 실시간 모니터링
- LCD 디스플레이로 분류 결과 표시
- 24시간 안정적 가동

## 📊 시스템 구조

```
Raspberry Pi 4B (상위)
  ↓ YOLOv8 딥러닝 추론
  ↓ UART 신호 송신
Arduino UNO R3 (중위) - 본인 담당
  ↓ GPIO/PWM 제어
드라이버 & 모터 (하위)
  ↓ 기계 동작
```

---

## 🔧 내가 개발한 부분

### 1) 핀맵 설계
- 센서 (홀센서, IR센서, 버튼)
- 모터 제어 (DC, 스테핑, 서보)
- I2C LCD 디스플레이

### 2) 모터 제어
- **DC모터**: PWM으로 속도 조절
- **스테핑모터**: 90도씩 정밀 회전
- **서보모터**: 180도 개폐 제어

### 3) 상태 머신
- 7가지 상태로 복잡한 프로세스 관리
- 명확한 상태 전환 로직

### 4) Serial 통신
- 한 문자 프로토콜 설계
- 신뢰도 높은 통신

### 5) 코드 진화 (V1→V3)
- **V1**: 기본 제어
- **V2**: 센서 통합
- **V3**: LCD 디스플레이 + 실시간 카운팅

---

## ⚡ 가장 어려웠던 문제: 전력 문제

### 증상
DC모터 구동하면 UART 통신이 끊어짐

### 분석 과정
```
Step 1: 프로토콜 확인 ✓
Step 2: 연결 상태 확인 ✓
Step 3: 전원 공급 확인 ⚡ ← 발견!

공통 그라운드 전압 변동이 원인
```

### 해결
**전원 배선 분산** → 전압 변동 최소화

### 배운 점
```
문제 해결 순서:
전원 → 신호 → 타이밍 → 로직
```
