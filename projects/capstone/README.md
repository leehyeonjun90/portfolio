# 고급임베디드 도어락 시스템 (기말과제)

## 프로젝트 개요

고급임베디드시스템 강의의 기말과제로 개발한 스마트 도어락 시스템입니다. 임베디드 시스템의 핵심 개념을 적용하여 실제 동작하는 도어락 제어 시스템을 구현했습니다.

## 기술 스택

- **Language**: C++ (Embedded)
- **Platform**: Microcontroller (ARM/AVR 기반)
- **Concepts**: 인터럽트, 타이머, I/O 제어, 상태머신
- **Hardware**: LED, 버튼, 모터, 센서

## 프로젝트 구조

```
capstone/
└─ src/
   └─ door_lock_system.cpp
```

## 주요 기능

### 1. 도어락 제어
- 모터를 이용한 자동 잠금/해제
- 상태머신 기반 제어 로직

### 2. 사용자 입력
- 버튼을 이용한 명령 입력
- 다중 인터럽트 처리

### 3. 상태 피드백
- LED를 통한 시스템 상태 표시
- 센서를 통한 도어 상태 감지

### 4. 안전 기능
- 타이타임아웃 처리
- 에러 상태 관리
- 비상 해제 기능
