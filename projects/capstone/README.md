# 스마트 도어락

**기말과제 - IoT 보안 시스템**

---

## 📌 프로젝트 개요

### 한 문장 요약
**Raspberry Pi 기반 IoT 보안 시스템 - GPIO와 PWM을 활용한 자동 문 제어**

---

## 🎯 핵심 기능

### 1. 키패드 입력
- 4자리 비밀번호 인증
- 디바운싱으로 신호 안정화

### 2. 자동 문 개폐
- 서보모터 180도 정밀 회전
- 성공/실패 피드백

### 3. 센서 통합
- 자석센서: 문 상태 감지
- LED: 상태 표시
- 부저: 경보음

### 4. 사용자 인터페이스
- 초록/빨강 LED 표시
- 성공/오류 음
- 비밀번호 변경 기능

---
